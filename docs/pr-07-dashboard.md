# PR 07 — Fiche entreprise et évolution des fondamentaux

La fiche affiche l’industrie, la capitalisation et la valeur d’entreprise quand le profil courant les fournit. Le bloc séparé charge à la demande les historiques de cours et les points de `/api/fundamentals/ratios`. Les sélecteurs changent la période (annuelle, trimestrielle ou TTM), la fenêtre (3, 5 ou 10 ans) et l’indicateur. La fenêtre est mesurée depuis la dernière fin de période disponible ; les bornes réelles et le nombre de périodes sont affichés, sans présumer une couverture complète. La courbe utilise les dates réelles et ne relie pas les points séparés par une valeur absente connue. Le tableau rend les valeurs, unités, sources, qualités, formules, entrées et raisons accessibles sans dépendre du survol. Des unités ou devises différentes bloquent la courbe. Les cours utilisent uniquement l’historique réel, avec source, couverture et fraîcheur du cache. Le profil courant n’est pas reporté dans le passé.

Les ratios et les TTM sont calculés par PR 06, pas par le navigateur. Les actions historiques correspondent aux actions diluées moyennes publiées, distinctes du nombre courant en circulation. Une devise financière historique peut provenir de métadonnées Yahoo actuelles non vérifiées. Les données, dates de publication et observations indisponibles restent absentes ; les périodes non fournies ne peuvent pas être déduites du seul graphique. La valeur d’entreprise attend un profil fournisseur qui la communique (extension PR 09). Les entreprises fictives ne chargent pas d’historiques réels. Les contrôles d’états financiers et de DCF existants restent disponibles.

Validation : `npm test`, tests Python, `TMPDIR=/workspace/work npm run test:browser`. Le test Chromium dédié navigue dans la vraie application et utilise uniquement des réponses synthétiques interceptées dans sa fixture isolée ; il vérifie fenêtres, sélection, tableau, provenance, absence, erreur, cours et absence d’écriture de l’état. La route ratios est fournie par PR 06 et doit être testée lors de l’intégration cumulée.
